# Obtenir les informations d'un indicateur ODD par son code exact

Obtenir les informations d'un indicateur ODD par son code exact

## Usage

``` r
sdg_indicator_info(code)
```

## Arguments

- code:

  Code de l'indicateur (ex. "4.1.1").

## Value

Une liste avec `goal`, `target`, `code`, `label_en`, `unit_hint`.
